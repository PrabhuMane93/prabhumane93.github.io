1. The attention formula

Every token in a sequence needs to decide how much to "listen to" every other token before updating its own representation. Attention is the mechanism that does that, and the whole thing collapses into one line:

Attention = softmax( QKT √dmodel )V

The formula takes four inputs: Q, K, V, and d_model.

Q
Query matrix
K
Key matrix
V
Value matrix
d_model
embedding dimension
Seq_Len is how many tokens. d_model is each token's embedding width. Together, X is Seq_Len × d_model, one row per token, as shown above.

We'll develop intuition for these inputs, and for why the formula is structured this way, later in the blog. For now, let's look at attention as a sequence of four mechanical steps.

Step 1

Attention = softmax( QKT √dmodel )V

Transposing K, then multiplying it by Q.

Q and K are both (Seq_Len × d_model) matrices, the same shape, since every token gets projected into both a query and a key. Before they can be multiplied, K has to be transposed to (d_model × Seq_Len) first. Transposing lines up every token's key vector along columns instead of rows, so multiplying Q by KT pairs each token's query row against every other token's key column. What comes out, one row and one column per token, is a raw, unnormalized attention score for every token against every other token in the sequence.

  • In real kernels this scaling step is rarely its own pass. It's usually combined into step 1's matmul, so one dispatch computes Q·KT and applies the scale at the same time. You'll see this shortly.
  • matmul is short for matrix multiplication.

Step 2

Attention = softmax( QKT √dmodel )V

Scaling by 1/√d_model, and calling the result S.

Before the raw scores go into softmax, we stabilize them by dividing every entry by √d_model, for numerical stability. Call this rescaled matrix S.

Step 3

Attention = softmax( S )V

Row-wise softmax of S, giving the attention map A.

Softmax runs one row at a time, not across the whole matrix. Each row of S holds one token's raw scores against every other token in the sequence, so normalizing that row on its own is what turns it into a distribution over just that token's attention targets. For a single row's entry xi, softmax is:

s(xi) = exi Seq_LenΣj=1exj

The numerator exponentiates one entry; the denominator exponentiates and sums every entry in the row, so dividing by it is what forces the row to add up to 1. Applying this does two things:

  • It rescales the row so every value sums to exactly 1, so the row behaves like a genuine probability distribution instead of a set of arbitrary numbers.
  • It exaggerates the gaps between scores: low values get pushed toward vanishingly small, and high values get pushed toward dominating the row, so a token ends up concentrating its attention on a handful of others rather than spreading it out evenly.

Step 4

Attention = A ·V

The final multiplication, A·V, gives the attention output.

The row of A for our token tells us how much it relies on every other token in the sequence. To compute our token's new value, we go feature by feature: for a single feature, take that feature's value from every other token, scale each one by how much our token attends to it, and add them all up. Do that across every feature, and you get our token's entire new row. Mechanically, that's the whole step: it's just a matrix-matrix multiplication, A times V.
